이메일로 계정 삭제 요청

앱 없이 요청하기

ramible.dev@gmail.com으로 이메일을 보내 주세요. 제목에 “Rivet Rumble 계정 삭제 요청”, 내용에 닉네임과 로그인 방식(게스트·아이디·연결 계정)을 적어 주세요. 답장을 받을 수 있는 이메일로 보내면 소유 확인 방법과 처리 결과를 안내합니다. 이메일 주소가 같다는 이유만으로 계정 소유를 인정하거나 계정을 삭제하지 않습니다.

앱에서 직접 요청하기

해당 계정으로 로그인한 뒤 계정 관리에서 계정 탈퇴를 선택하세요. 현재 비밀번호, 연결 제공자의 새 인증 또는 해당 게스트 기기의 인증으로 본인 확인이 필요합니다. 버튼 위치와 제공되는 로그인 방식은 앱 버전에 따라 달라질 수 있습니다.

삭제되는 데이터

본인 확인 후 해당 계정의 로그인·세션·연결 정보, 닉네임·친구 관계, 로봇·부품·보석과 게임 진행을 운영 서버에서 삭제합니다. 진행은 복구할 수 없으므로 대상 계정을 확인해 주세요. 앱 삭제나 로그아웃만으로 서버의 계정이 삭제되지는 않습니다.

별도로 남을 수 있는 기록

복구용 서버 백업은 최대 30일 이내 만료되며, 탈퇴 계정을 복구하는 데 사용하지 않습니다. 삭제 여부를 나타내는 최소 기록과 가명 처리된 공동 전투 결과는 게임 진행과 분리해 서비스 운영 기간 동안 보관합니다. 실제 거래에 전자상거래법상 보관 의무가 적용되는 경우 계약·청약철회 및 대금결제·공급 기록은 5년, 소비자 불만·분쟁처리 기록은 3년, 표시·광고 기록은 6개월을 기준으로 게임 진행과 별도로 보관합니다. 보관기간의 법적 근거를 확인할 수 있으며, 요청 처리 시 해당 계정에 남는 기록과 기간을 안내합니다.

게스트 계정과 본인 확인

게스트 인증 정보가 있는 원래 기기에서 요청하는 것이 가장 확실합니다. 기기를 바꾸거나 앱 데이터를 삭제해 인증 정보를 잃은 경우 닉네임만으로는 소유 확인이 어려울 수 있습니다. 문의 메일에 비밀번호·인증코드·구매 전체 토큰·카드번호·신분증이나 주민등록번호를 보내지 마세요.
