# RAMIBLE Studio

Static, bilingual studio and game information website.

- Korean: `index.html`
- English: `en.html`
- Website privacy: `privacy.html` and `privacy-en.html`
- AdMob authorized sellers: `/app-ads.txt`

No build tools, third-party JavaScript, game runtime, account system, analytics or embedded payment processing.

## Local preview

```sh
python3 -m http.server 8891 --bind 127.0.0.1
```

## Publication

Intended for GitHub Pages. Publishing must be approved by the owner. Keep `app-ads.txt` at the website domain root. The website privacy notice covers this information website; it is separate from the game's own data and consent policy.

The game icon is an existing RAMIBLE Studio project asset.
